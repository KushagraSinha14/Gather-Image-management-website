# Gather — Event Management Website

A responsive event discovery and registration website built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Responsive layout for mobile, tablet and desktop
- Upcoming event cards with event details
- Search events by title, category, venue or description
- Filter events by category
- Event details modal and registration form
- JavaScript validation for name, email and Indian mobile number
- Registration confirmation message
- Saves registrations in browser Local Storage

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For a local development server, use the VS Code Live Server extension.

## Project files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — event data, search, filters, modal and registration logic

## Notes
This is a frontend demonstration. Registration details are saved only in the visitor's browser using Local Storage; there is no backend database or email notification.

## Deployment
You can deploy this folder using GitHub Pages, Netlify or Vercel.
